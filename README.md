# Data_Cleaning_Titanic
Data cleaning using pandas on Titanic dataset
## Data cleaning steps performed
1. Loaded Titanic dataset using pandas
2. Checked dataset struture using head() and info()
3. Identified missing values using isnull().sum().
4. Filled missing values with median.
5. Filled categorical missing values with mode
6. Dropped irrevelant column [cabin]
7. Remove duplicate rows
8. Converted datatypes where necessary.
9. saved the cleaned dataset as a csv file
